# User Support & Feedback Operations

## 1. In-Product Feedback System
Users can submit feedback directly from the dashboard.
*   **Categories:** Bug, Medical Data Error, AI Concern, Security Concern, UI Issue.
*   **Routing:** Support tickets are routed to Zendesk/Jira based on priority.

## 2. Triage Matrix
| Category | Priority | SLA | Escalation |
|---|---|---|---|
| Security / Data Breach | P0 | < 1 hour | Security Team |
| Medical Record Missing | P1 | < 4 hours | DB Admins |
| AI Output Incorrect | P2 | < 24 hours | Data Science Team |
| UI Glitch | P3 | < 48 hours | Frontend Team |

## 3. Disclaimers
Support agents must remind users that:
*   MediChain does not provide medical advice.
*   Users must contact 911 for emergencies.
*   AI predictions are informational only.
